# RTX 5090 (sm_120) — quality → memory → speed

27B-class model (FP8 weights), NVFP4 KV cache, 262k context on 32 GB.

```
vllm serve <model-fp8> \
  --kv-cache-dtype nvfp4 \
  --max-model-len 262144 \
  --max-num-seqs 2 \
  --block-size 32 \
  --gpu-memory-utilization 0.97 \
  --enable-chunked-prefill --max-num-batched-tokens 4096 \
  --enable-auto-tool-choice --tool-call-parser <parser> \
  --reasoning-parser <parser>
```

Key decisions, each measured:

- **Plain (uncalibrated) checkpoint** with `--kv-cache-dtype nvfp4` — baked
  per-tensor amax KV scales *cost* 1.67 pp GSM8K at 4 bit (see README finding
  2026-08-01). vLLM defaults k/v scales to 1.0; rare sink outliers clip
  harmlessly at the block ceiling (needle-verified to 240k tokens).
- **No speculative decoding** — MTP would cost ~71k tokens of KV pool; on this
  box memory is the scarce resource, not decode speed (~67 tok/s single-stream,
  ~125 tok/s batched-8 as measured).
- Requires the consumer-Blackwell NVFP4-KV serving path (vllm#46329 +
  flashinfer#3684 kernels).
